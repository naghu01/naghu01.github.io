# Portfolio – Najeeb GHULAM

Portfolio BTS SIO option SLAM (École IRIS, Paris) : réalisations E5 / E6, stages, compétences et veille technologique sur les cybermenaces du retail et du luxe.

Site statique en HTML, CSS et JavaScript, sans framework, publié avec GitHub Pages.

- `index.html` : page unique du portfolio
- `style.css`, `mediaqueries.css` : styles et responsive
- `script.js` : menu mobile et navigation active
- `assets/livrables/` : documents téléchargeables (procédures, rapports)
